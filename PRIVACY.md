# Privacy Policy

**WTFDoesThisMean**  
Last updated: November 18, 2026

WTFDoesThisMean is a browser extension that helps users understand English words and build their vocabulary.

## Information We Handle

The extension handles the following information:

- **Groq API key:** You provide your own API key, which is stored locally in your browser using Chrome's extension storage.
- **Vocabulary:** Words, definitions, and example sentences are stored locally in your browser.
- **Lookup requests:** When you request an explanation, the word is sent to the Groq API to generate the response.

## How We Use Information

Information is used only to provide the extension's vocabulary explanation and saving features.

We do not operate our own backend server or collect vocabulary data on our own servers.

## Third-Party Services

WTFDoesThisMean uses the Groq API to generate word explanations.

When you request an explanation, your lookup word and API key are sent to Groq. Their handling of this information is governed by [Groq's Privacy Policy](https://groq.com/privacy-policy/).

## Data Storage and Security

Your API key and saved vocabulary are stored in your browser's local extension storage.

This storage is not encrypted by the extension. Keep your API key private and do not share it.

All API requests to Groq use HTTPS.

## Data Sharing

We do not sell, rent, or independently share your information. The lookup word and API key are sent to Groq only to provide the requested explanation.

## Changes to This Policy

This policy may be updated when the extension's functionality or data practices change.
